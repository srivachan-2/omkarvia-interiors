# OMKARVIA Interiors Website Demo

A responsive, front-end-only website concept for OMKARVIA Interiors, using navy blue, gold, ivory, and the OMKARVIA office background image.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser. No build step or package installation is required.

## Included sections
- Hero with continuously floating Flexible EMI headline and auto-scrolling service/value ribbon
- Quote form and modal (demo only; no visitor data is sent or stored)
- Business benefits: flexible EMI enquiry, transparent estimates, model reference designs, end-to-end execution
- Why OMKARVIA approach
- EMI explanation and eligibility/terms disclaimer
- Service categories: complete home interiors, modular kitchens, living rooms, bedrooms, wardrobes/storage, office interiors, TV units and custom furniture
- Design collections: budget, premium, luxury and modern
- Five-step design-to-handover process
- Contact details from the current OMKARVIA website: Hyderabad, info@omkarvia.in, +91 94938 06363
- Responsive navigation, WhatsApp link, and scroll reveal animations
